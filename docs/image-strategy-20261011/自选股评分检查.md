# 自选股评分功能检查

检查日期：2026-10-11。检查对象为桌面端实际使用的 backend/web/app.js、backend/api/webapi.py 及 portfolio 模块。

当前结论：**自选股页面没有自动评分标注功能。**

- 页面列为代码、名称、分组、收盘、涨跌、成交量、加入理由及删除操作，没有综合分、图片策略分、A/B/C档位或评分更新时间。
- `/api/watchlist` 返回自选记录与价格数据，没有调用每日推荐评分器，也没有返回 score/factors。
- `portfolio.mark_watch()` 能保存文字标记，数据库有 last_mark、last_mark_at、priority 字段；priority 是排序优先级，不能当成交易评分。当前页面也未展示 last_mark。
- `portfolio.health_score()` 与 scripts/portfolio_health.py 已有持仓健康度评分，但服务于持仓检查，不是全部自选股的每日选股评分。
- 每日推荐页已有评分，本次接入的图片蒸馏因子权重为60%；自选股恰好进入推荐清单时，可在推荐页看到评分，但未入选不等于零分，也不能代表所有自选股都已评估。

本次按要求完成检查，没有自动增删自选股。若后续接入，应直接复用相同评分器，并对所有自选股逐只显示综合分、图片分、数据日期和缺失/硬过滤原因；不宜只从每日Top列表反查后把未上榜股票记成0分。
