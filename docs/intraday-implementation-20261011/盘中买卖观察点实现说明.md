# 盘中买卖观察点：实现与验收

2026-10-11，北京时间。已接入当前安装的 Opus 0.2.1；安装目录的 local-settings.json 指向此项目，后端及网页改动直接生效。

## 使用

在「自选股」点击股票，进入「个股详情」，将「周期」选择为「分时」或 1／5／30／60 分钟。日线仍可选择。

- B：买点观察，S：卖点观察；实心为规则确认，空心问号为候选。
- R：历史样本逐根回放。它不代表系统当时已运行或提示过该信号。
- 灰色 ×：后续结构计算已失效。图上默认隐藏，可勾选显示；下方记录始终保留。
- 图上标记定位于首次可计算的已完成 K 线，表格分别列出首次可计算 K 线、实际发现时间、结构发生时间／价格。当时收盘价与结构价分开列出。
- 分时为最新有数据交易日的一分钟收盘价连线，不是逐笔行情，不包含未完成分钟，不伪造均价线；成交量为股换算到手。
- 页面可见时每 15 秒检查更新；后台交易时段轮询分钟源，单股单周期最短约 30 秒一次，真实延迟还取决于来源和跟踪池规模。软件需保持运行，最小化到托盘可继续。
- 未加入自选或持仓的股票不主动采集。新增／移除跟踪股在后续轮询生效，持仓数量未知（NULL）也纳入监控。

行情缺失、网络异常、未返回当前已完成分钟、采集时间超过 120 秒时，暂停新增盘中记录。恢复后补算的历史数据标为回放，不补造过去的实时提醒。休市时明确显示历史回看。

观察点为既有缠论规则的辅助提示，不代表预测胜率或自动交易指令。弱三买等属于候选，已确认结构也可能后续失效。卖点需使用者自行核对 T+1、可用持仓与流动性。此改动不改变图片蒸馏因子在每日选股中的 60% 权重，不接券商下单。

## 数据与实现

- 来源：腾讯公开分钟接口，实测 m1／m5／m30／m60 的时间网格正确；每次本机响应 482 根，不能按请求 count 假定返回长度。
- 新缓存：`data/opus-intraday.sqlite`，与日线 DuckDB 隔离，避免读写连接及跨进程锁冲突。
- `bars` 保存校验后的完成分钟线；`feeds` 保存源时间、抓取时间和错误；`signals` 保存首次观察；`revisions` 追加失效／恢复等变更。
- 按交易时段的周期网格、OHLC、成交量和有限数值校验；收盘后保留 5 秒发布宽限。未来及形成中的 K 线不进入分析，不补造午休或停牌 K 线。
- 首次建立缓存时逐前缀重放，发现时间标为实际运行时间，首次可计算时间仅表示本次有限历史窗口内的结果。原始历史不足会影响缠论结构，不能宣称全历史首次信号。
- 既有缓存有新增完成 K 线时增量分析；过期、启动回放、长时间断线补算及来源历史修订不冒充实时观察。首次观察记录不会因重算而改写。
- `/api/intraday/{code}?period=m1` 与日线全市场可用日期独立，避免当天日线未齐导致盘中图被拒绝或退回前一日。
- 服务由 Web API 生命周期启动，不启动旧的全量调度器；测试用 `OPUS_INTRADAY_DISABLE=1` 隔离。既有新闻、邮件服务保留。
- 当前为单一公开分钟源；来源异常时保留历史图并明确停用新增盘中提示，不把缓存冒充实时数据。
