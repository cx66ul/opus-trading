## 1. 一分钟了解项目

**定位**：A股个人辅助交易决策系统。**决策副驾，不接券商下单接口**。

**核心能力**：行情采集 → 数据入库 → 因子/策略计算 → 信号输出 → 邮件报告 → 前端展示。

**不可违背的三条铁律**（写在这里是因为接手的人最容易破坏它们）：

| # | 铁律 | 违反后果 |
|---|---|---|
| 1 | **接口 + 注册表**，换实现不改核心代码 | 一改就到处是补丁 |
| 2 | **纯函数引擎** `f(输入, as_of, params)`，禁 `datetime.now()`/`time.time()` | 回测结果不可复现，且**不报错** |
| 3 | **抓取与解析分离**，原始报文先落 `raw_news` | 上游改格式时静默产出空数据 |

**配色约定**：涨=红、跌=绿（**仅行情**）。服务状态用 `.ok`/`.bad` 绿/黄，两套不可混。

## 4. 语料口径确认结果

用户于 2026-10-11 确认 10 项口径，全部记录在 `data/scope_answer_sheet.md`。

| # | 术语 | 确认口径 | 与项目现状 |
|---|---|---|---|
| Q1 | 跌停 | 分母=全市场，含 ST | ✅ 一致 |
| Q2 | 大盘 | **上证指数** | ⚠ **原为等权均值代理，已改** |
| Q3 | 涨停 | 分母=全市场，**排除 ST** | ✅ 一致 |
| Q4 | 成交量 | **两市合计、单位=成交额** | ✅ 一致 |
| Q5 | 市值 | **流通市值** | ⚠ 单位是**元**，用时须 `/1e8` |
| Q6 | 连板 | **高度**（几连板） | ✅ 已实现 `max_streak` |
| Q7 | 红盘 | **指数收红** | ⚠ 依赖 Q2，已改 |
| Q8 | 亏钱效应 | 跌停家数 **+ 封单量增减** | ❌ **封单量无数据源，未实现** |
| Q9 | 面积 | `跌停/(涨停+跌停)` | ✅ 已统一（详见 4.1） |
| Q10 | 万手 | 单只股票 | — |

### 4.1 Q9 分母修订的过程（重要）

用户先答「分母=全市场股票数」，后修订为 `跌停/(涨停+跌停)`。

**原分母会让规则永不触发**：
- `跌停/全市场`：实测中位 **0.19%**、最大 0.55% ⇒ **242 天里 0 天超过 30%**
- `跌停/(涨停+跌停)`：中位 26.8% ⇒ 243 天里 **23 天超过 30%**

⇒ 这正是「哑弹规则」的典型：阈值写死、校验通过、页面显示「已上线」，但**永不触发且不报错**。

### 4.2 Q2 的教训：等权均值冒充指数

原 `backfill_regime.py` 用 `breadth.avg_chg`（**全市场个股等权均值**）当大盘涨跌。当时标注是诚实的（`index_pct_source="equal_weight_avg"`，注释写着「不冒充上证指数」），所以没被发现。

**实测 30 个交易日，两者符号经常相反**：

| 日期 | 等权% | 上证% | 差(pp) |
|---|---|---|---|
| 2026-09-09 | −0.469 | **+0.278** | +0.747 |
| 2026-09-16 | +1.418 | +0.707 | −0.711 |
| 2026-09-21 | +1.919 | +0.972 | −0.946 |
| 2026-10-09 | +0.608 | +0.050 | −0.558 |

根因：等权 vs 市值加权。**市场状态会判反，且不报任何错**。

已改为真实指数，251 行 `index_pct_source` **全部 `sh000001`**，守护在 `tests/test_regime_index.py`。

### 5.2 token 提取

token 在 `localStorage["czone-web-antd-1.2.3-prod-core-access"]` 的 **JSON 里**的 `accessToken` 字段（**不是裸值**）。

工具：`C:\tmp\hawkacc\read_browser_token.py`
```bash
python C:/tmp/hawkacc/read_browser_token.py --port 9225 --write-c
```

★ 必须用 **Python**（不是 Node）：本机实测同一时刻 `curl` 与 Python 通、Node `fetch`/`http.get` 报 ECONNREFUSED。

★ 首次运行时我犯过一个错：只按「值以 `eyJ` 开头」找 token ⇒ 在包着 JSON 的形态上**报「未登录」，而页面明明已登录**。这是最坏的一类误报：**把「我找不到」说成「它没有」**。

### 5.3 前端接入

`GET /api/platform` —— **三态分开返回**，不一律 500（共 11 个端点）：

| state | 含义 | 前端提示 |
|---|---|---|
| `ok` | 可达且登录态有效 | 正常 + 配额表 |
| `unauthorized` | 能连但 token 失效 | 「登录态失效，需重新登录」 |
| `unreachable` | 网络不通 | 「内网/VPN 未连」 |

混成一个「失败」会让用户以为是系统坏了。位置：Web 端「系统状态」页。

### 5.4 备份死纪律 ★★

**用户 2026-10-11 指示：「每次做完训练都要备份数据作为死纪律」**

## 7. 桌面端（Electron）

### 7.1 已实测跑通的链路

```
窗口创建 → shell.html（启动画面）
        → did-finish-load → 启动 Python 后端
        → 后端 running → 跳转到主界面 http://127.0.0.1:PORT/
```

实测证据：窗口 URL = `http://127.0.0.1:8874/`，标题 = `Opus 辅助交易 · 决策副驾`，`/api/health` = **200**。

### 7.2 关键设计决定

| 决定 | 理由 |
|---|---|
| 单实例锁 | 两实例会抢 DuckDB 写锁，表现为「数据库已被占用」 |
| 关窗最小化到托盘 | 每次看盘都重开十几秒服务，久而久之就不用它了 |
| 退出必须清场 | 留孤儿占端口 ⇒ 下次启动报「端口被占用」 |
| `contextIsolation: true` + `sandbox: true` | 渲染进程不给 Node 权限 |
| preload 只暴露 6 个具名函数 | 暴露 `ipcRenderer` 等于放开全部主进程权限 |
| 向导用**三态**（pass/skip/block） | 一律当失败 ⇒ 被无关项挡住；一律当通过 ⇒ 真阻断项漏过 |
| 更新必须 sha256 校验 | 自动更新最危险的失败是「下到坏包还覆盖了能用的版本」 |
| 首屏加载壳层而非主界面 | 后端没起时只剩浏览器错误页，用户既看不到原因也没重试入口 |

### 7.3 打包

```bash

cd desktop && npm run dist               # 打包
```

### 9.3 ★ 写判据时反复踩到的坑

这一节比任何单条判据都值钱 —— **判据本身会骗你**：

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **注释/docstring 污染子串判据** | 注释里写着「不要写 `shares>0`」⇒ 判据永远红 | 用 AST 只看真实调用/节点 |
| **判据被注释里的字样触发** | 我写「不能有 `logger &&`」，注释里正好有这个 | 同上 |
| **固定字符窗口** | `i+60` 刚好截在参数前 ⇒ 判据恒失效 | 按行块/结构判定 |
| **`if False:` 伪装** | 把 return 包进 `if False:` ⇒ 判据仍绿 | AST 判「无条件可达」 |
| **Python 解析 JS** | `ast.parse` 在对象字面量 `{a: 1}` 处报错 | 按行正则，别跨语言解析 |
| **看源码字符串不如看文件** | 源码写对了但文件被移走 | 直接检查文件是否存在 |

**每一次判据写完都必须做变异测试**：故意改坏源码，确认测试变红，然后还原。已做 12+ 次。

### 11.4 数据库

| 事项 | 说明 |
|---|---|
| DuckDB **单写者** | 写用 `get_conn()`，读用 `get_ro_conn()` |
| ★ `get_ro_conn()` 是**进程级单例**，任何地方都不能 `close()` | 否则之后所有用例报 `Connection already closed!`，只在全量跑时暴露 |
| 同进程内 `read_only=True` 与读写连接**不能共存** | 全量跑时新测试用 `get_conn()` 会抛 `different configuration` |
| DuckDB **支持 `?` 占位符**（1.5.6 实测） | 旧记忆记「不支持」已过时 |
| `ATTACH` 是 DDL，**不支持占位符** | 路径须内插 + 转义引号 + 拒绝分号 |
| 窗口子查询必须一起 `select trade_date` | 否则 `Referenced column not found` |
